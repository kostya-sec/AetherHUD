# 键盘导航与焦点模型（UI Spec v1）

- 票：[#17 决策·无鼠标/键盘导航与焦点模型](https://github.com/kostya-sec/AetherHUD/issues/17)（2026-10-21 结案）
- 用途：PRD v2「键盘可达」章节的施工依据；前端（React 19 + Tauri v2 webview）实现依据。
- 上位约束：#7（交互范式与视觉）、#8（卡片操作集与生命周期）、#9（L3 标签治理与筛选栏顺序）、#10（taxonomy 1.1.0，含「00 未分类」）、#12（常驻 / 失焦收起 / 托盘）、#16（唤出即聚焦搜索框；**2026-10-23 需求变更：默认收起、点搜索球才展开并聚焦**）。
- 硬验收（#16）：Windows/macOS 上「唤出 → 输入 → 选 L1/L2 → 切 L3 → 打开卡片 → Esc 收起」全程无需鼠标。

## 1. 一句话模型

HUD 的键盘界面 = **五个焦点区 + 一个搜索气泡**：Tab 换区、方向键在区内移动、Enter 使用当前项、Esc 收起；中文输入法组合态下所有按键让给输入法。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 默认态 | 唤出后的初始界面：搜索框（空、聚焦）+ 球列；无卡片流、无 L2 面板、标签条收起 |
| 搜索气泡 | 默认态下输入查询时浮在搜索框下方的结果列表（≤5 条命中 + 「查看全部」行） |
| 分支浏览态 | 已选中 L1/L2 或已点亮 L3 标签、卡片流可见的状态 |
| 搜索结果视图 | 从气泡「查看全部 N 条结果」进入的卡片流状态：显示全部命中，无 L1/L2 |
| 焦点区 | 一组共享键盘焦点的控件（同一时刻区内只有一个可聚焦项） |
| 键盘模式 | 最近一次交互来自键盘（用于焦点环显示），由根节点的 data-kbd 属性标记 |

## 3. 视图状态与迁移

| 状态 | 进入条件 | 界面 |
| --- | --- | --- |
| S0 默认态 | 唤出；或清空全部筛选与查询 | 球列（顶部为搜索球）+ 搜索框收起（2026-10-23 需求变更：默认不展开、不聚焦；点搜索球才展开并聚焦） |
| S1 搜索气泡态 | S0 且查询非空 | S0 + 搜索气泡 |
| S2 分支浏览态 | 选中 L1 / L2，或点亮任一 L3 标签 | L2 面板（选 L1 后）+ 卡片流；查询非空时在当前筛选内 AND 过滤，不出气泡 |
| S3 搜索结果视图 | 在 S1 激活「查看全部 N 条结果」 | 卡片流显示全部命中（无 L1/L2），面包屑「搜索：<查询>」；L3 可叠加 |

迁移规则：

- **每次唤出强制回到 S0**（#17-Q2=B）：清空 L1/L2/L3、查询、面板展开态、卡片滚动位置、气泡。HUD 是随手唤出的浮层，「每次干净起点」比「恢复上次现场」更可预期。
- S2 中清空查询与全部筛选 → S0；S3 中清空查询 → 有筛选则 S2，否则 S0。
- 标签条展开是正交 UI 状态：S0/S2/S3 都可展开；点亮标签即进入 S2。
- 打开详情 / 快速录入 / 设置弹窗不改变底层状态；关闭后焦点回原处。
- **2026-10-23（#28）**：快速录入弹窗与收件箱列表视图都是浮层，Esc 先关浮层、再收起 HUD；
  两个浮层打开时整窗铺 backdrop（点击不穿透），底部提示条隐藏、键位提示写在浮层自身。
  设置球入口行是原地展开条（非浮层），Esc 收起入口行；其 ←→/Home/End 导航与五区循环
  接线在 #38。

## 4. 焦点区

| 区 | 何时存在 | 区内移动 | 回上层 |
| --- | --- | --- | --- |
| 搜索框 | 总是 | 文本光标（原生） | —（↑ 无动作） |
| 搜索气泡 | S1 | ↑↓ / Home / End | 首项再 ↑ 或 Tab → 搜索框 |
| 球列 | 总是 | ↑↓ / Home / End | 首球再 ↑ → 搜索框 |
| L2 面板 | S2（选了 L1） | ↑↓ / Home / End | ← → 球列 |
| L3 标签条 | 展开时 | ←→ / Home / End | Tab 离开（下一区 = 卡片流；Shift+Tab = L2 或球列） |
| 卡片流 | S2 / S3 | ↑↓ / Home / End / PgUp / PgDn | 首条再 ↑ → 搜索框 |

规则：

- Tab / Shift+Tab 的循环顺序：搜索框 → 球列 → L2（若存在）→ 标签条（若展开）→ 卡片流（若存在）→ 搜索框。**气泡不参与循环**，其 Tab 回搜索框。
- 区内同一时刻只有一个可聚焦项（roving tabindex）；方向键移动焦点并更新 tabindex。
- 区被重新进入时，焦点回到该区上次停留的项（会话内记忆；唤出时重置）。
- 鼠标点击区内任意项 → 焦点落到该项（键鼠混用）；鼠标悬停不移动焦点。
- 焦点到达区内边界不循环，只有上表的「回上层」键离开。

## 5. 键位总表

修饰键：Mod = Windows Ctrl / macOS Cmd。删除只用 Delete，Backspace 不绑定删除。

### 5.1 全局

| 键 | 行为 |
| --- | --- |
| 唤出/收起热键（#16，可重绑定；默认值见 #12/PRD） | 切换显隐；唤出 → S0（球列 + 搜索框收起，2026-10-23 需求变更：不自动聚焦，点搜索球才展开） |
| Esc | 有弹窗/浮层 → 关闭最上层（详情 / 快速录入 / 设置 / 键位表）；否则收起 HUD。输入法组合态例外见 §7 |
| Tab / Shift+Tab | 下一区 / 上一区；气泡内回搜索框 |
| ?（Shift+/） | 打开键位表浮层；输入区内不触发 |
| Mod+Z | 撤销最近一次删除（5 秒 toast 内）；不移动焦点 |

不拦截：Mod+A/C/X/V/Z 等系统编辑键；输入框内方向键与 Home/End（原生光标移动）。

### 5.2 搜索框

| 键 | 行为 |
| --- | --- |
| Enter | 把焦点推进结果第一项：S1 → 气泡首项；S2/S3 → 卡片流首条。空查询或无结果时不动作 |
| ↓ | 同 Enter；S0 空查询、无气泡时 → 球列第一个球 |
| Mod+Enter | 打开快速录入弹窗并带入当前输入（#7 的 Ctrl+Enter 入库；macOS 上 Ctrl 与 Cmd 均接受） |
| Esc | 收起 HUD（组合态只取消候选） |

说明：搜索框 v1 固定为单行；**2026-10-23 需求变更：唤出默认收起、点搜索球才展开并聚焦（取代 #16 的「唤出即展开」）**；收起状态下球列顶部显示搜索球。

### 5.3 搜索气泡（S1）

| 键 | 行为 |
| --- | --- |
| ↑↓ / Home / End | 移动高亮 |
| Enter | 普通命中：展开该条的 L1/L2 → 进入 S2，卡片流定位到该条目并聚焦（封存/回收站命中见 §8）；「查看全部 N 条结果 →」：进入 S3 |
| Tab / Shift+Tab | 回搜索框 |
| Esc | 收起 HUD |

规则：

- 最多 5 条命中；命中总数 > 5 时末尾追加「查看全部 N 条结果 →」。
- 排序：FTS5 相关度（bm25）优先，同分按 last_seen 倒序。
- 无命中：显示「没有匹配的条目」，不产生可聚焦项，↓/Enter 不动作。
- 每条展示：标题 + L1›L2 + 命中片段；封存/回收站/failed 条目带状态徽标。
- 出现条件：查询非空且**没有任何筛选生效**。任何筛选生效（L1/L2/L3 任一）时不出气泡，搜索改为在卡片流内 AND 过滤。
- 气泡随查询实时更新（150ms 防抖）；焦点在气泡内时查询变化，高亮重置到首项。

### 5.4 球列

| 键 | 行为 |
| --- | --- |
| ↑↓ / Home / End | 球间移动 |
| Enter 或 → | 触发当前球（见下） |
| Tab / Shift+Tab | 换区 |
| Esc | 收起 HUD |

球类型与触发语义：

- **L1 球**（含「00 未分类」，共 5 个）：选中该分类 → 展开 L2 面板，焦点送「全部子类」。
- **L3 筛选球**：展开标签条，焦点送第一个 pill。
- **快速录入球**：打开快速录入弹窗，焦点进内容输入框。
- **设置球**：打开设置，焦点进第一个控件（设置页用原生 Tab）。
- **搜索球**（仅在鼠标收起搜索框后出现）：重新展开搜索框并聚焦。

不提供 L1 数字直选（分类数会变、数字与名称无记忆关联、IME/键盘布局差异下易误触；5 个球用 ↑↓ 足够快）。

### 5.5 L2 面板

| 键 | 行为 |
| --- | --- |
| ↑↓ / Home / End | 移动 |
| Enter 或 → | 选中：普通子类 = 选中该 L2；「全部子类」= 仅保留 L1；随后焦点进卡片流首条 |
| ← | 回球列（L2 面板保持展开） |
| Esc | 收起 HUD |

- 卡片流为空时焦点留在 L2，卡片流显示空态文案。
- ← 是「层级回退」，与卡片的 ↑「回搜索框」（空间回退）分工不同。

### 5.6 L3 标签条

| 键 | 行为 |
| --- | --- |
| ←→ | 按视觉顺序线性遍历所有 pill（跨行折行）；Home / End 到条首 / 条尾 |
| Space 或 Enter | 切换该 pill 的选中态 |
| Mod+L | AND / OR 逻辑切换（#7 默认 AND） |
| Mod+Backspace | 清空全部 L3 筛选（媒体 + 形态 + 特征） |
| Tab / Shift+Tab | 离开（下一区 = 卡片流；上一区 = L2 或球列） |
| Esc | 收起 HUD |

- 遍历顺序 = #9 的呈现顺序：媒体 chip → 形态标签（5 个恒显）→ 特征标签。
- 置灰 pill（当前分支零匹配，见 #9）不进入焦点顺序，位置保持稳定。
- 「+N」折叠 pill 可聚焦，Enter 展开（#9 的两行折叠）。
- 不设「收起标签条」键：展开态在本次唤出内保持，唤出时重置；鼠标的 × 按钮保留。

### 5.7 卡片流

| 键 | 行为 |
| --- | --- |
| ↑↓ | 移动；首条再 ↑ → 搜索框；末条再 ↓ → 特殊行（加载更多 / 已完成折叠行） |
| Home / End | 首条 / 末项（含特殊行） |
| PgUp / PgDn | 按可视页翻动 |
| Enter | 打开原文链接（系统浏览器）；HUD 按失焦逻辑收起（#12，250ms 宽限） |
| Space | 打开详情弹窗（焦点进首个可编辑项；关闭后回原卡片） |
| C | 复制 Markdown 引用（#8 格式，含分类路径与标签） |
| P | 置顶 / 取消置顶（#8：当前过滤结果内的排序权重） |
| Delete | 移入回收站（软删）+ 5 秒撤销 toast；Mod+Z 撤销 |
| R | 重新入队重试（仅 pipeline_status = failed 的条目；#8 的卡片级操作） |
| Tab / Shift+Tab | 换区 |
| Esc | 收起 HUD |

- 特殊行（参与 ↑↓ 与 Home/End）：
  - 「加载更多」：列表底部，Enter 载入下一页（50 条 / 页）。
  - 「已完成 (N)」折叠行：Enter 展开 / 收起；展开后的已完成条目可正常聚焦与操作（视觉降透明度，见 #8）。
- 鼠标单击卡片 = 打开详情（#7 现状不改）；键盘对应键是 Space，Enter 专用于打开原文。
- 多选批量操作 v1 不做。
- 搜索结果视图（S3）里封存 / 回收站命中带徽标；Delete 对已在回收站的条目不动作（toast 说明）。

### 5.8 弹窗、设置与帮助

- **详情弹窗**：原生 Tab 顺序；Enter / Space 激活控件；多行文本内 Enter 换行；Mod+Enter 保存并关闭；Esc 关闭（放弃未保存修改；「重新分类」的二次确认按 #8 保留）；关闭后焦点回原卡片。
- **快速录入弹窗**：打开即聚焦内容输入框；Mod+Enter 入库；Tab 原生；Esc 关闭。预填规避见 §9.8。
- **设置 / 标签管理 / 封存箱 / 回收站**：v1 只要求原生 Tab 顺序可达、可操作（#17-Q4=A）；Esc 关闭。
- **键位表浮层（?）**：按区分组、标注当前平台修饰键；Esc 或 ? 关闭。

## 6. 焦点可见性与键位提示

- **键盘模式**：非鼠标操作触发后给根节点加 data-kbd="1"；pointerdown 移除。焦点样式 = :focus-visible 或 [data-kbd] :focus 双保险（脚本 focus 不保证匹配 :focus-visible）。
- **焦点环**：外 1px 近黑 + 内 2px 琥珀 + 微光；透明窗口 / 任意壁纸下必须清晰可辨。选中态（pill 已选、卡片已置顶等）与焦点环是两种视觉，不能混用。
- 只给当前区的当前项画环（roving focus 天然保证）；区获得焦点时容器标题 / 左边框可轻微高亮。
- **底部键位提示条**：常驻一行，随当前区变化，例如：
  - 搜索框：Enter 进结果 · Mod+Enter 入库 · Tab 换区
  - 球列：↑↓ 选择 · Enter 进入 · Tab 换区 · Esc 收起
  - 卡片流：↑↓ 选择 · Enter 打开 · Space 详情 · C 复制 · P 置顶 · Del 删除
  - 标签条：←→ 选择 · Space 切换 · Mod+L 与/或 · Mod+Backspace 清空
- ? 打开完整键位表（按区分组）。提示条与键位表是键盘可发现性的硬要求（#17-Q5=A）。

## 7. 输入法、连发与修饰键

- **组合态判定**：event.isComposing 或 event.keyCode === 229 或 event.key === 'Process' → 所有 HUD 快捷键让给输入法（含方向键、Enter、Esc）。
- **组合结束宽限窗**：自维护组合标志，组合结束后 100ms 内 Esc 不收起 HUD、单字母不触发。原因：WKWebView 在部分版本先给 compositionend、再给 isComposing=false 的确认键 keydown（WebKit 317127，2026-06 起多次开关）。
- Esc 的全局动作延后一拍（rAF / setTimeout(0)）再判定，避免与输入法事件同帧竞争。
- **连发**：动作键（Enter / Space / C / P / R / Delete / Mod+*）忽略 event.repeat；导航键（↑↓←→ / PgUp / PgDn）允许连发。
- 唤出时不主动切换输入法；输入框内不劫持系统编辑键；单行搜索框是 IME 安全区（见 tauri#15436 的预填 textarea 坑）。

## 8. 边界与异常态

| 场景 | 行为 |
| --- | --- |
| 查询无命中 | 气泡空态；↓ / Enter 不动作；不收起 HUD |
| 分支无条目 | 卡片流空态文案；焦点留在 L2 |
| 命中 > 5 | 气泡末尾「查看全部 N 条结果 →」→ S3 |
| 长列表 | 50 条 / 页 + 加载更多行；PgDn 到底不自动加载（防误触） |
| 命中封存 / 回收站条目 | 激活后进入 S2，该条目临时插入当前分支卡片流顶部并聚焦、带徽标（否则它在默认流不可见，焦点无处可落）；Delete 对回收站条目不动作 |
| failed 条目 | 卡片带错误徽标，R 重试（#8） |
| 打开原文时窗口失焦 | 按 #12 自动收起（250ms 宽限） |
| 唤出 / 收起动画 | 唤出动画期间不阻塞输入（焦点与输入立即可用）；收起动画期间吞掉键盘事件（防二次触发）；收起开始即归还焦点 |
| 搜索请求竞态 | 150ms 防抖 + 丢弃过期响应 |
| 多显示器 / 窄窗口 | 气泡与卡片流不超出窗口；气泡按可用高度收缩并内部滚动 |

## 9. 实现约定（给实现 agent）

1. **键盘路由**：HUD 根节点单一 keydown 监听（capture），处理顺序 = 输入目标放行 → 组合态放行 → 当前区路由 → 全局键 → 默认行为；只在真正处理时 preventDefault。
2. **焦点管理**：每区一个 tabindex=0 的当前项；区切换用 focus({ preventScroll: true }) + 滚动到可视区；区记忆；唤出时强制 focus 搜索框。
3. **焦点环**：data-kbd 模式类（键盘事件置 1、pointerdown 置 0），样式用 :focus-visible 与 [data-kbd] :focus 并集。
4. **ARIA**：气泡 / L2 / 卡片流 = listbox + aria-selected；球列 / 标签条 = toolbar；搜索框 = searchbox；toast = aria-live="polite"。不作为 v1 验收项，但不得妨碍键盘。
5. **搜索**：FTS5 trigram（#10）；150ms 防抖；相关度排序；按查询键缓存结果。
6. **卡片流**：50 条 / 页；v1 不虚拟滚动（性能目标在地图的「Not yet specified」）。
7. **唤出焦点**：依赖包含 tauri#15625 修复的 Tauri 版本；show() → set_focus()；Windows 前台锁失败时校验并重试；禁止 focusable(false)。
8. **快速录入预填**：tauri#15436（Windows 预填内容的 textarea 首次聚焦会冻结 TSF IME）→ 先聚焦空输入、下一帧再赋值，或预填到普通 input；验收用中文输入法实测。
9. **动画**：唤出动画开始前完成 focus；收起动画期间移除键盘路由。

## 10. PRD v2「键盘可达」验收条目

> 2026-10-23 需求变更：唤出默认显示球列、搜索框收起（K1 已注明）。下表步骤里的「唤出 → 输入」在 v1 实现中应先点搜索球展开搜索框；T14 若为搜索区补全局键位，再回填此处。

| ID | 步骤 | 通过标准 |

## 13. 与既有决议的关系（不重复定义）

- #7：视觉与交互范式（球原地展开、搜索框 / 标签条 / 卡片流布局、Esc 退场动画）→ 本 spec 只补键盘层与搜索气泡。

- #10：taxonomy 1.1.0（5 个 L1，含「00 未分类」）→ 球列内容。
- #12：失焦收起、托盘、单实例 → 打开原文后的收起与焦点归还。
- #16：唤出与「焦点进搜索框」→ S0 的起点；**2026-10-23 需求变更：唤出不再聚焦搜索框，点搜索球才展开并聚焦**；本 spec 落实「全程键盘可达」。

## 14. 风险与待验证

- 中文输入法在 Windows（TSF / WebView2）与 macOS（WKWebView）的组合态行为差异大，必须真机验收 K7 / K10。
- 「搜索结果视图」的相关度排序在 FTS5 trigram 下的效果待数据量验证（#10 的容量旋钮）。
- 唤出焦点依赖 Tauri 修复版本与 Windows 前台锁，需在 K1 中回归。
- 「已完成」折叠行与「加载更多」行的焦点顺序为 v1 约定，实测后可微调（不改变键位）。
